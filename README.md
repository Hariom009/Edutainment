📌 Overview

Edutainment is an interactive educational app designed for children to practice multiplication tables in a fun and engaging way. The app allows users to select a number range and solve multiplication problems while tracking their scores.

🎯 FEATURES

Select a custom number range for practicing multiplication tables.

Score panel that updates as users move to the next question.

A reset button to start a new game session.

Score button in the toolbar to display the current score.

User-friendly and engaging interface for children.



🛠️ TECHNOLOGIES USED 

SwiftUI for building the user interface.

State Management using @State for dynamic updates.

NavigationView & Toolbar for better user experience.


📖 USAGE

Open the app and select a number range.

Solve multiplication questions presented in the selected range.

Keep track of your score via the score panel.
